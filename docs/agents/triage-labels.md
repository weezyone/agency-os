# Triage Labels

The skills use five canonical triage roles. This table maps each role to its label in this repository's GitHub issue tracker.

| Label in mattpocock/skills | Label in our tracker | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Maintainer needs to evaluate this issue |
| `needs-info` | `needs-info` | Waiting on the reporter for more information |
| `ready-for-agent` | `ready-for-agent` | Fully specified, ready for an AFK agent |
| `ready-for-human` | `ready-for-human` | Requires human implementation |
| `wontfix` | `wontfix` | Will not be actioned |

When a skill mentions a role, use the corresponding label string from this table. For example, "apply the AFK-ready triage label" means `ready-for-agent`.

Edit the "Label in our tracker" column if the repository adopts a different vocabulary.
